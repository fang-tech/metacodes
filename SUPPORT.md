# Support

- Use [GitHub Discussions](https://github.com/metask-ai/metacodes/discussions)
  for usage, embedding and design questions.
- Use issues for reproducible bugs and concrete proposals (the issue forms ask
  for what is needed).
- Use private security advisories for vulnerabilities ([SECURITY.md](SECURITY.md)).
- Include the metacodes commit or `metacodes --version` output, Zig version,
  OS/architecture, provider kind, and relevant sanitized logs.

Provider credentials, prompt content, tool results, TinyKG stores, and user files
must be removed from diagnostics unless explicitly required and safely shared.
